# AI Based Smart College Helpdesk & Student Support System

A web-based college helpdesk system designed to help students quickly access college information, student services, and AI-based assistance.

## Features

- 🤖 AI Helpdesk
- 🔎 College Search
- 🎓 Admission Information
- 💰 Fees Information
- 📝 Examination Information
- 📖 Library Information
- 🏠 Hostel Information
- 💼 Placement & Career Support
- 🎁 Scholarship Information
- 🏅 Sports Information
- 📢 College Notices
- 📱 Mobile-friendly interface

## Technology Used

### Frontend
- HTML
- CSS
- JavaScript

### Backend
- Node.js
- HTTP Server
- REST API

### Development Environment
- Termux
- Android
